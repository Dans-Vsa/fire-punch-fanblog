# FIRE PUNCH — Dunia Membeku, Satu Api

Blog fan **Fire Punch** (ファイアパンチ) karya Tatsuki Fujimoto. Bagian dari [Fujimoto Archive](https://dans-vsa.github.io/fujimoto-archive/).

**Live:** https://dans-vsa.github.io/fire-punch-fanblog/

Tema "Frozen Ink": halaman manga hitam-putih di tengah badai salju abadi, dan satu-satunya warna adalah api.

- Badai salju interaktif. Kursor melelehkan salju, dan menahan klik di hero "menyalakan" halaman.
- Profil karakter (bebas spoiler).
- Lima arc dengan teaser. Ringkasan spoilernya membeku di bawah es dan baru meleleh saat diklik.
- Peta 83 bab, rak 8 volume, fakta, dan link baca resmi.
- Dwibahasa ID / EN.

HTML/CSS/JS murni tanpa build step. Spesifikasi desain ada di [DESIGN.md](DESIGN.md).

Sumber fakta: Wikipedia dan Fire Punch Wiki (Fandom). Gambar karakter dan sampul volume berasal dari Fire Punch Wiki, dipakai untuk ulasan penggemar.
